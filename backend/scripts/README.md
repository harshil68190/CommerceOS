# scripts/

Home for one-off operational scripts that are not part of the running API
or a background worker — e.g. seeding reference data, one-time data
backfills, or admin utilities.

This milestone (backend foundation) adds no scripts, since there is no
data or models yet to seed or migrate. The folder is created now, per the
architecture's folder structure, so this remains the single place future
scripts go rather than being scattered wherever is convenient at the
time.
